# Витта — демо сайта салона-парикмахерской (Новосибирск)

Персональное демо на базе шаблона Mirelle для салона-парикмахерской «Витта», проспект Дзержинского, 22. Сделка LID-39.

Сайт статический: `index.html` + `assets/` (css, js, images). Сборка не нужна.
Весь контент лежит в `assets/js/config.js`.

## Откуда данные
- **Прайс:** каталог услуг салона в 2ГИС (38 позиций, обновлён 31.03.2026). В демо 5 вкладок: окрашивание, стрижки и причёски, маникюр и педикюр, брови и ресницы, лицо и татуаж.
- **Фото:** галерея салона в 2ГИС, только фото салона, без снимков клиентов. Первый экран, фото услуги при наведении в прайсе, портфолио по направлениям, мастера за работой.
- **Отзывы:** подтверждённые отзывы из 2ГИС, дословно, с сокращениями.
- **Контакты:** часы ежедневно 8:00–20:00, адрес, способы оплаты, WhatsApp/Telegram/ВК, рейтинг 4,9 / 202 оценки — 2ГИС. Телефоны — 2ГИС и jsprav.ru. Почта — из задачи.
- **Цвета и логотип:** фиолетовый и нежно-розовый с фирменных подарочных сертификатов (фото в 2ГИС); логотип набран рукописным шрифтом по мотивам фирменного.
- **FAQ:** только факты из карточки 2ГИС (часы, адрес и остановка, оплата, подарочные сертификаты).

## Что скрыто
- **«До/после»:** в галерее нет парных снимков одной работы (есть только коллаж из трёх кадров без подписей). Включается в `config.js` → `show.beforeAfter`, когда салон пришлёт пару фото.

## Согласовать с салоном перед публикацией
- Использование фото из галереи 2ГИС. Сейчас они подгружаются с сервера 2ГИС; после согласования их нужно скачать в `assets/images` и поменять ссылки в `PHOTO` в `config.js`.
- Фото мастеров в блоке «Наша команда»: согласие и подписи (имя, специализация).
- Цитаты отзывов из 2ГИС (в них упоминаются мастера Василина, Галина Николаевна, Светлана).
- Акция на сложное окрашивание «от 5 900 ₽» (указана в 2ГИС, срок неизвестен) и актуальность цен.

## Чего не хватает от салона
- Логотип в векторе
- Парные фото «до/после» (лучше всего — сложное окрашивание)
- Длительность услуг (в калькуляторе пока только стоимость)
- Имена и специализации мастеров
- Ссылка на онлайн-запись (YClients/DIKIDI), если есть; сейчас запись через WhatsApp
- Реквизиты для подвала
